# مولّد الجذاذة التربوية – التربية الإسلامية

تطبيق سطح مكتب عربي RTL لإنشاء جذاذات التربية الإسلامية وفق قالب تربوي ثابت قابل لإعادة الاستخدام. يعمل محلياً ويحفظ البيانات بصيغة JSON داخل مجلد Documents، ولا يعتمد أثناء الاستخدام على خادم أو API أو اتصال بالإنترنت.

## التقنية

النواة الحالية مكتوبة بلغة Python باستخدام Tkinter للواجهة، و`json` للتخزين المحلي، و`zipfile` لإنشاء ملفات DOCX حقيقية قابلة للتحرير، وReportLab لتوليد PDF. هذه البنية مناسبة لتغليف التطبيق لاحقاً داخل ملف Windows مستقل بواسطة PyInstaller، بحيث لا يحتاج المستخدم النهائي إلى Python أو Node.js أو npm.

## تشغيل نسخة التطوير

```text
python app/main.py
```

على Windows ينشئ التطبيق مجلد البيانات تلقائياً داخل `%LOCALAPPDATA%\Tarbawi-Jodada`، بينما يستخدم مجلد Documents عند التشغيل على Linux. تحفظ البيانات في `data.json`، وتحفظ ملفات التصدير في مجلد `exports`.

## الوظائف المنفذة

يتضمن الإصدار الحالي الصفحة الرئيسية، إنشاء الجذاذة وتعديلها، مكتبة الجذاذات، البحث، النسخ والحذف، القالب الأساسي ذي المراحل الرسمية، القوالب القابلة للنسخ، تحرير الأنشطة والأسئلة والسندات، تسجيل الفرضيات، الربط التلقائي بمرحلة تمحيص الفرضيات، القيم، التقويم، التعلم الذاتي، الحفظ التلقائي، المعاينة، تصدير Word وPDF، الطباعة عبر معاينة HTML، والإعدادات والنسخ الاحتياطي والاسترجاع.

## الاختبار

```text
python tests/test_core.py
```

## بناء Windows للمستخدم المبتدئ

افتح مجلد المشروع على Windows وانقر مرتين فقط على الملف الموجود في الجذر باسم `BUILD-WINDOWS.bat`. ينشئ الملف بيئة بناء تلقائية، ويثبت الاعتماديات المطلوبة، وينشئ النسخة المحمولة داخل `release/Tarbawi-Jodada-Portable`.

إذا كان Inno Setup مثبتاً، ينشئ الملف `release/Tarbawi-Jodada-Setup.exe` تلقائياً. إذا لم يكن مثبتاً، يفتح الملف رابط تنزيله ويعرض رسالة واضحة؛ بعد تثبيته انقر مرتين على `BUILD-WINDOWS.bat` من جديد.

المطلوب مرة واحدة فقط قبل النقر على الملف هو تثبيت Python 3.11 أو أحدث مع تفعيل خيار `Add Python to PATH`. لا يحتاج المستخدم النهائي إلى Python أو Node.js أو npm بعد الحصول على النسخة التنفيذية.

يوجد أيضاً Workflow في `.github/workflows/windows-build.yml` مخصص لـ Windows Runner. عند تشغيله من مستودع GitHub يقوم تلقائياً بالاختبارات وبناء EXE ونسخة Portable وملف Setup، ثم يحفظها كملفات قابلة للتنزيل. لم يتم تشغيل هذا Workflow في الجلسة الحالية لعدم وجود حساب GitHub موثق أو مستودع متصل.

## النسخ الاحتياطي

من صفحة الإعدادات اختر «نسخ احتياطي» لحفظ كل الجذاذات والقوالب والإعدادات في ملف JSON، واختر «استرجاع نسخة» لاستعادتها على هذا الحاسوب أو حاسوب آخر.

## ملاحظات الإصدار

الإخراج الحالي يضمن ملف DOCX حقيقياً قابلاً للفتح والتحرير، بينما يحتاج إخراج الجداول المعقدة المطابق تماماً للنموذج المرجعي إلى مرحلة لاحقة من محرك الإخراج، مع اختبار عملي على Microsoft Word وWindows. لذلك لا تُعد هذه الحزمة بعدُ مثبت Windows نهائياً؛ إنها نسخة مصدر قابلة للبناء واختبار النواة والوظائف الأساسية.
